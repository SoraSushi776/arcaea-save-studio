生成预览

先生成再看这里
曲目难度定数分数 PURESHINYFARLOST单曲 PTT

它怎么算 PTT

score ≥ 10,000,000                 → 定数 + 2 + 奖励
9,800,000 ≤ score < 10,000,000     → 定数 + 1 + (score - 9,800,000) / 200,000 + 奖励
score < 9,800,000                  → max(0, 定数 + (score - 9,500,000) / 300,000 + 奖励)

PTT = (Best50 总和 + Best10 总和) / 60

Best50 是历史最高的 50 个单曲潜力值，前 10 个再计一遍（双倍权重）。奖励默认按 0.2 计算，和社区资料一致。

生成器做了什么

给定目标 PTT 后，程序先按「前 10 名比其余高一点」的形状构造 Best50，再用二分把整体 PTT 校准到目标值；随后把每条目标潜力值反推成自洽的分数与 PURE / SHINY / FAR / LOST 计数，最后给其余谱面填充不会挤进 Best50 的历史成绩。

数据来源

曲目表、物量、定数来自社区维护的 Arcaea 数据（songlist 7.1.0）。导出的 st3 结构与游戏内 SQLite 存档一致。

注意

导出的存档仅用于本地游玩或研究，上传服务器可能被判定异常。使用前记得备份原档。
